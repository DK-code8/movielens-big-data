# MovieLens Exploratory Analysis

Exploratory analysis of the MovieLens 100K ratings dataset with pandas. It covers rating distributions,
user activity, movie popularity and user demographics.

**Course:** Introduction to Big Data, Deree – The American College of Greece (Fall 2024)

## Tech
Python · pandas · NumPy · Matplotlib

## Contents
- `Intro to big Data Project/Intro_Big_data.py`: analysis script

## Data
The MovieLens 100K dataset is **not included** because its licence does not allow redistribution.
Download `ml-100k.zip` from [GroupLens](https://grouplens.org/datasets/movielens/100k/) and extract the
`u.*` files into `Intro to big Data Project/`.

## How to run
```bash
pip install pandas numpy matplotlib
cd "Intro to big Data Project"
python Intro_Big_data.py
```
